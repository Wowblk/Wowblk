## Projects

### [TitanX](https://github.com/Wowblk/TitanX)

Python Agent SDK / 框架，围绕 Model-Tool Loop 构建运行时，包含工具授权、策略控制、上下文压缩、审计和沙箱执行模块。

A Python framework for agent runtimes, with tool authorization, context compaction, policy controls, audit logging, and sandbox backends.

[快速开始与架构](https://github.com/Wowblk/TitanX#readme) · [安全边界](https://github.com/Wowblk/TitanX/blob/main/SECURITY.md)

### [KnowFlow](https://github.com/Wowblk/KnowFlow)

知识社区与 AI 助手项目。Spring Boot 后端、React 前端和 Go gateway 组成应用，TitanX Agent 支持内容检索、整理和草稿创建。

A knowledge community with an AI assistant, built with Spring Boot, React, a Go gateway, and TitanX.

[项目说明与运行方式](https://github.com/Wowblk/KnowFlow#readme)

### [video-bilingual-notes](https://github.com/Wowblk/video-bilingual-notes)

将视频、课程和访谈整理为保留原文的中英对照阅读文档，附时间戳与对应截图。Codex skill 负责翻译与校核，Python 工具检查来源覆盖并生成 Markdown 和 HTML。

A Codex skill and Python helper for complete bilingual video notes with transcripts, timestamps, and screenshots.

[安装与示例](https://github.com/Wowblk/video-bilingual-notes#readme)
